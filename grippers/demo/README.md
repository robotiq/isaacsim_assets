# Isaac Sim demos

Two demos live here:

- **teleop**: UR5e + Robotiq gripper driven from a gamepad or keyboard, no ROS. See
  [teleop/README.md](teleop/README.md) to get started.
- **TSF-85 tactile sensor**: open one scene, press Play, and watch a live 7×4 tactile heatmap while you
  grip with a gamepad trigger. See [TACTILE_DEMO.md](TACTILE_DEMO.md).
